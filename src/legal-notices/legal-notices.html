Relink notice (LGPL-3.0 — "work that uses the Library")
--------------------------------------------------------------------------------

The libvips shared library is dynamically linked by the `sharp` addon at
runtime; it is a separate, identifiable, and user-replaceable file. You may
modify the library and relink it against a modified version of
`libvips-cpp.so.42` / the equivalent .dll / .dylib without modifying
haxtheweb-desktop itself. To do so:

  1. Obtain the libvips source (see the LGPL-3.0 section above).
  2. Build your modified `libvips-cpp` shared library.
  3. Replace the file at the following location inside the application bundle:
       - Linux:   <app>/resources/app/node_modules/@img/sharp-libvips-linux-x64/lib/libvips-cpp.so.42
       - Windows: <app>\resources\app\node_modules\@img\sharp-libvips-win32-x64\lib\win32-x64\libvips-cpp.dll
       - macOS:   <app>.app/Contents/Resources/app/node_modules/@img/sharp-libvips-darwin-x64/lib/libvips-cpp.dylib
  4. Relaunch the application.

The application's own source code (Apache-2.0) is available at:
    https://github.com/haxtheweb/desktop
